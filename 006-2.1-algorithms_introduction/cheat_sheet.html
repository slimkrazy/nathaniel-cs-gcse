Key Concepts Summary

What is an Algorithm?

Definition: A step-by-step set of instructions to solve a problem or complete a task.

Think of it like: A recipe, a set of directions, or instructions for building LEGO.

🔹 Decomposition

Definition: Breaking a complex problem down into smaller, more manageable sub-problems.

Why use decomposition?
  • Makes big problems less overwhelming
  • Each small problem is easier to solve
  • Different people can work on different parts
  • Easier to test individual pieces
Example: Creating a Video Game

Big problem: Create a platform game

Decomposed into:

  • Character movement (left, right, jump)
  • Platform collision detection
  • Coin collection system
  • Score tracking
  • Display and graphics

🔸 Abstraction

Definition: Removing unnecessary details and focusing only on what's important.

Why use abstraction?
  • Simplifies the problem
  • Reduces complexity
  • Helps you focus on what matters
  • Makes problems easier to understand
Example: Driving a Car

Without abstraction: Engineering view (fuel injection, transmission ratios, combustion cycles, thousands of sensors)

With abstraction: Driving interface (steering wheel, pedals, gear stick, speedometer)

Result: Can drive without understanding how engines work! The controls hide the complex mechanics.

Flowchart Shapes

Flowcharts are visual diagrams showing algorithm steps using standard shapes.

START

Oval (Terminator)

Used for: START and END

Example: START, END, STOP

x = x + 1

Rectangle (Process)

Used for: Instructions, calculations, operations

Example: x = x + 1, Set count to 0

INPUT age

Parallelogram (Input/Output)

Used for: Getting input or showing output

Example: INPUT age, OUTPUT total

age ≥ 18?

Diamond (Decision)

Used for: Yes/No questions, conditions

Example: age ≥ 18?, x > 10?

Note: Always has 2 paths (YES/NO)

📏 Drawing Flowcharts:
  • Arrows show the flow direction
  • Flow direction: Usually top-to-bottom
  • Label arrows from diamonds (YES/NO)
  • Every flowchart starts with START and ends with END

The Three Programming Constructs

1️⃣ Sequence

What it is: Instructions executed one after another in order

Pseudocode:
START name = "Nathaniel" age = 14 OUTPUT name OUTPUT age END
Flowchart Pattern:
    ╭─────────╮
    │  START  │
    ╰────┬────╯
         ▼
    ┌─────────┐
    │ Process │
    └────┬────┘
         ▼
    ┌─────────┐
    │ Process │
    └────┬────┘
         ▼
    ╭─────────╮
    │   END   │
    ╰─────────╯

Straight line down
No branching!

2️⃣ Selection (IF statements)

What it is: Making decisions - program takes different paths based on a condition

Pseudocode:
START INPUT age IF age ≥ 18 THEN OUTPUT "Can vote" ELSE OUTPUT "Too young" ENDIF END
Flowchart Pattern:
    ╭─────────╮
    │  START  │
    ╰────┬────╯
         ▼
    ╱──────────╲
   ╱ INPUT age  ╲
   ╲─────┬──────╱
         ▼
      ╱────╲
     ╱      ╲ YES
    ╱ age≥18?╲───────┐
    ╲        ╱        │
     ╲──┬───╱         ▼
        │NO     [Process]
        ▼             │
   [Process]          │
        │             │
        └──────┬──────┘
               ▼
          ╭────────╮
          │  END   │
          ╰────────╯

Diamond creates 2 paths!

3️⃣ Iteration (Loops)

What it is: Repeating a set of instructions multiple times

Pseudocode (FOR loop):
START FOR i = 1 TO 5 OUTPUT i ENDFOR OUTPUT "Done!" END
Pseudocode (WHILE loop):
START i = 1 WHILE i ≤ 5 OUTPUT i i = i + 1 ENDWHILE OUTPUT "Done!" END
Flowchart Pattern:
    ╭─────────╮
    │  START  │
    ╰────┬────╯
         ▼
    ┌─────────┐
    │ i = 1   │
    └────┬────┘
         │
    ┌────▼────┐
    │         │
    ▼         │
 ╱────╲       │
╱ i≤5? ╲ NO   │
╲      ╱──────┼──────┐
 ╲─┬──╱       │      │
   │YES       │      │
   ▼          │      │
[Process]     │      │
   │          │      │
   ▼          │      │
┌─────────┐   │      │

                ╭────────╮

                ╰────────╯

Arrow loops back up!
🔁 Loop Types:
  • FOR loop: Use when you know how many times to repeat
  • WHILE loop: Use when repeating as long as a condition is true
  • Both look similar in flowcharts — key feature is the loop-back arrow!

Quick Reference Guide

Identifying Constructs in Flowcharts

If you see... It's a... Construct Type
Straight line of shapes going down Sequence One step after another
Diamond with two branches (YES/NO) Selection IF statement decision
Arrow that loops back upward Iteration FOR or WHILE loop

Common Exam Tips

  • ✅ Always start with START and end with END
  • ✅ Use the correct shape for each step
  • ✅ Label YES/NO paths from decision diamonds
  • ✅ Arrows show direction of flow
  • ✅ Every diamond must have exactly 2 exits (YES and NO)
  • ✅ Loops have an arrow going backward to repeat

  • ⚪ Oval = START/END
  • ▭ Rectangle = Process
  • ▱ Parallelogram = Input/Output
  • ◇ Diamond = Decision (YES/NO)
