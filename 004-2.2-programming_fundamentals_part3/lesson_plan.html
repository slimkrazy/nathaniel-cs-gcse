Count-Controlled Loops (FOR loops) - Visual Learning (10 minutes)

🔢 Count-Controlled (FOR Loop)

When you know EXACTLY how many times to repeat

Visual Pattern: for i in range(5): print(f"Count: {i}") What happens: i = 0 → "Count: 0" i = 1 → "Count: 1" i = 2 → "Count: 2" i = 3 → "Count: 3" i = 4 → "Count: 4" STOP (5 times total)
🎯 Like: Shooting 10 arrows at a target
🏃‍♂️ Like: Running 5 laps around a track
🎵 Like: Playing a song 3 times

❓ Condition-Controlled (WHILE Loop)

When you don't know how many times, but you know WHEN to stop

Visual Pattern: password = "" while password != "secret": password = input("Enter password: ") print("Access granted!") What happens: Check: password != "secret"? → YES Ask for password → "wrong" Check: password != "secret"? → YES Ask for password → "secret" Check: password != "secret"? → NO STOP → "Access granted!"
🎮 Like: Fighting a boss until health = 0
🍕 Like: Eating pizza until you're full
🔑 Like: Trying keys until one opens the door

Common Loop Patterns (7 minutes)

🎯 Essential Patterns Every Programmer Uses:

1. Counting Pattern
count = 0 for i in range(10): count = count + 1 print(f"I counted to {count}")
2. Accumulation Pattern (Adding Up)
total = 0 for i in range(1, 6): # 1, 2, 3, 4, 5 total = total + i print(f"Sum of 1+2+3+4+5 = {total}")
3. Validation Pattern (Keep Asking)
age = -1 while age < 0: age = int(input("Enter your age (must be positive): ")) print(f"Thanks! You are {age} years old.")
4. Menu Pattern (User Choice)
choice = "" while choice != "quit": print("1. Play game 2. Settings 3. Quit") choice = input("Choose: ") print("Goodbye!")

Common Mistakes & Debugging (3 minutes)

⚠️ Watch Out For These Traps!

1. Infinite Loop (WHILE Loop that Never Stops)
x = 1 while x < 10: print(x) # FORGOT: x = x + 1 # This runs FOREVER!
2. Off-by-One Error (Wrong Range)
# Want: Print 1, 2, 3, 4, 5 for i in range(5): # Gets: 0, 1, 2, 3, 4 print(i + 1) # CORRECT: Add 1 # OR BETTER: for i in range(1, 6): # Gets: 1, 2, 3, 4, 5 print(i)
3. Indentation Errors
# WRONG: for i in range(3): print(i) # Not indented - runs once after loop # CORRECT: for i in range(3): print(i) # Indented - runs each loop iteration

Bringing It All Together - The Three Constructs in Action (4 minutes)

🎮 Game Example: All Three Constructs Working Together

name = input("Enter your name: ") # SEQUENCE: Get input score = 0 # SEQUENCE: Initialize variable if len(name) > 0: # SELECTION: Check if name entered for attempt in range(3): # ITERATION: 3 attempts allowed guess = int(input("Guess 1-10: ")) # SEQUENCE: Get guess if guess == 7: # SELECTION: Check if correct score = score + 10 # SEQUENCE: Update score print("Correct!") # SEQUENCE: Give feedback else: # SELECTION: Wrong answer print("Try again!") # SEQUENCE: Encourage retry print(f"{name}, final score: {score}") # SEQUENCE: Show result else: # SELECTION: No name entered print("Please restart and enter your name") # SEQUENCE: Error message
🔍 Spot the Constructs:
  • 🟢 SEQUENCE: Lines that run one after another (input, print, variable assignment)
  • 🟡 SELECTION: if/else decisions that choose what to do
  • 🔵 ITERATION: for loop that repeats the guessing game

Key Insight: "Real programs combine all three constructs to create complex, interactive experiences!"

Quick Practice & Wrap-up (2 minutes)

🧠 Quick Mental Check:
