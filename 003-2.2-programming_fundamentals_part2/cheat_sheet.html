🔗 Connection to Boolean Logic

Boolean Logic (Hardware)

  • AND gate: Output True when both inputs True
  • OR gate: Output True when at least one input True
  • NOT gate: Output opposite of input

Programming Logic (Software)

  • and operator: True when both conditions True
  • or operator: True when at least one condition True
  • not operator: Flips True ↔ False

🔢 Comparison Operators

Purpose: Compare values and return True or False
Operator Meaning Example Result
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
< Less than 3 < 5 True
> Greater than 5 > 3 True
<= Less than or equal 5 <= 5 True
>= Greater than or equal 5 >= 3 True
⚠️ CRITICAL: = assigns, == compares!
age = 16 (store 16 in age)
age == 16 (check if age equals 16)

🔀 IF Statement Syntax

Basic IF

if condition: # code to execute if True statement1 statement2

IF-ELSE

if condition: # code if True statement1 else: # code if False statement2

IF-ELIF-ELSE

if condition1: # code if condition1 is True elif condition2: # code if condition2 is True elif condition3: # code if condition3 is True else: # code if all conditions are False
🔧 Key Rules:
  • Every if/elif/else line ends with :
  • Code inside must be indented (4 spaces or 1 tab)
  • Only the first True condition executes in if-elif chain
  • else is optional and runs if all conditions are False

📋 Quick Examples

Simple Decision

age = 16 if age >= 18: print("You can vote!") else: print("Too young to vote")

Multiple Conditions (AND)

temperature = 22 sunny = True if temperature > 20 and sunny: print("Perfect weather!")

Multiple Conditions (OR)

weekend = True holiday = False if weekend or holiday: print("No school today!")

Grade Calculator

score = 85 if score >= 90: grade = "A" elif score >= 80: grade = "B" elif score >= 70: grade = "C" elif score >= 60: grade = "D" else: grade = "F" print(f"Grade: {grade}")

Complex Condition

age = 16 has_permit = True has_adult = True if age >= 18: print("Can drive alone") elif age >= 16 and has_permit and has_adult: print("Can drive with supervision") else: print("Cannot drive")

⚡ Order of Operations

Priority (highest to lowest):
  1. Parentheses: ()
  2. Comparison: ==, !=, <, >, <=, >=
  3. NOT: not
  4. AND: and
  5. OR: or
# Examples: True or False and False # True (and first) (True or False) and False # False (parentheses first) age > 18 and not tired or weekend # Same as: ((age > 18) and (not tired)) or weekend

🚨 Common Mistakes

❌ Wrong

if age = 18: # Assignment! if age == "18": # String comparison if 10 < age < 20 # Missing colon print("Teen") # Missing indentation

✅ Correct

if age == 18: # Comparison! if age == 18: # Number comparison if 10 < age < 20: # Has colon print("Teen") # Proper indentation

🎯 Quick Practice

Evaluate these expressions:

  1. 5 > 3 and 2 < 4 = ?
  2. True or False and False = ?
  3. not (5 == 5) = ?
  4. 10 >= 10 and not False = ?
Answers (click to reveal)
  1. True (both 5>3 and 2<4 are True)
  2. True (or has lower priority, so False and False = False, then True or False = True)
  3. False (5==5 is True, not True is False)
  4. True (10>=10 is True, not False is True, True and True is True)

💡 Memory Tips

  • == vs =: "Equals equals compares, single equals stores"
  • AND logic: "ALL conditions must pass" (like AND gate)
  • OR logic: "At least ONE condition must pass" (like OR gate)
  • Indentation: "Python cares about spaces - be consistent!"
  • Colons: "Every decision line ends with a colon"
