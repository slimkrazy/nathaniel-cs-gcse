Exercise 1: Gaming Profile Creator

Easy
Create a program that builds a gaming profile by collecting user information and displaying it in a stylish format using the Rich library.

📚 Concepts Tested

  • String variables and concatenation
  • Integer variables
  • Input and output with Rich
  • Basic conditional logic (if/else)
  • String formatting

📋 Requirements

  • Ask for the user's gamer tag, real name, age, and favorite game
  • Use Rich to make the input prompts colorful
  • Check if the user is old enough to play mature games (18+)
  • Display the profile in a nice panel with emojis
  • Add different messages based on their age group

🎨 Rich Examples to Help You

from rich.console import Console from rich.prompt import Prompt from rich.panel import Panel console = Console() # Colored input prompts name = Prompt.ask("[cyan]What's your name?[/cyan]") age = Prompt.ask("[yellow]How old are you?[/yellow]") # Converting string input to integer age_num = int(age) # Displaying in a panel profile_text = f"🎮 Name: {name}\n🎂 Age: {age}" console.print(Panel(profile_text, title="Gaming Profile", style="green"))

Exercise 3: Password Strength Checker

Medium
Build a cybersecurity tool that analyzes password strength and gives advice on creating secure passwords!

📚 Concepts Tested

  • String variables and methods
  • Boolean variables for conditions
  • Complex conditional logic with multiple criteria
  • String analysis (length, character types)
  • Nested if statements

📋 Requirements

  • Ask user to enter a password
  • Check password length (minimum 8 characters)
  • Check if it contains uppercase letters, lowercase letters, numbers, and symbols
  • Rate the password as Weak, Medium, or Strong
  • Give specific advice on how to improve it
  • Use colors: red for weak, yellow for medium, green for strong
  • Add security-themed emojis

🎨 Rich Examples to Help You

from rich.console import Console from rich.prompt import Prompt from rich.panel import Panel console = Console() password = Prompt.ask("[cyan]Enter password to check[/cyan]", password=True) # Checking different conditions has_upper = any(c.isupper() for c in password) has_lower = any(c.islower() for c in password) has_digit = any(c.isdigit() for c in password) has_symbol = any(not c.isalnum() for c in password) is_long_enough = len(password) >= 8 # Counting how many criteria are met strength_score = sum([has_upper, has_lower, has_digit, has_symbol, is_long_enough]) if strength_score >= 4: console.print("[green]🔒 Strong password![/green]") elif strength_score >= 3: console.print("[yellow]⚠️ Medium strength[/yellow]") else: console.print("[red]❌ Weak password![/red]")
Expected Output Example:
╭──── 🔐 Password Analysis ────╮
│ Length: ✅ 12 characters │
│ Uppercase: ✅ Found │
│ Lowercase: ✅ Found │
│ Numbers: ❌ Missing │
│ Symbols: ✅ Found │
│ │
│ 🟡 MEDIUM STRENGTH │
│ │
│ 💡 Try adding some numbers! │
╰──────────────────────────────╯

💡 Hints

  • Use password=True in Prompt.ask() to hide the password
  • Use string methods like .isupper(), .isdigit()
  • Count how many criteria are met to determine strength
  • Give specific advice based on what's missing

Exercise 4: Text-Based Adventure Game

Hard
Create an interactive story game that uses everything you've learned - variables, input/output, and complex decision-making!

📚 Concepts Tested

  • Complex nested conditional logic
  • String variables for story text
  • Integer variables for health/score
  • Boolean variables for game state
  • Input validation and error handling
  • Advanced Rich formatting and styling

📋 Requirements

  • Create a short adventure with at least 5 decision points
  • Track player health (starting at 100)
  • Track player score or gold using integer variables
  • Include at least 3 different endings based on choices
  • Use Rich to create immersive scenes with panels and colors
  • Add a combat system with conditional logic
  • Include character stats display (health, score)
  • Make it engaging with emojis and storytelling!

🎨 Rich Examples to Help You

from rich.console import Console from rich.panel import Panel from rich.prompt import Prompt, Confirm from rich import print console = Console() # Game variables player_health = 100 player_gold = 0 game_over = False # Creating dramatic scenes console.print(Panel( "[bold red]🏰 THE HAUNTED CASTLE 🏰[/bold red]\n\n" "You stand before a mysterious castle...\n" "Strange sounds echo from within...\n" "Do you dare to enter?", style="red", width=50 )) # Getting player choice choice = Prompt.ask( "\n[yellow]What do you do?[/yellow]", choices=["enter", "run", "investigate"] ) # Health display with colors def show_stats(): if player_health > 70: health_color = "green" health_emoji = "💚" elif player_health > 30: health_color = "yellow" health_emoji = "💛" else: health_color = "red" health_emoji = "❤️" console.print(f"[{health_color}]{health_emoji} Health: {player_health}/100[/{health_color}]") console.print(f"[yellow]💰 Gold: {player_gold}[/yellow]")

💡 Hints

  • Plan your story structure first - draw a flowchart!
  • Use functions to avoid repeating code (like stats display)
  • Use choices=[] in Prompt.ask() to limit valid options
  • Create variables to track different game states
  • Use nested if statements for complex branching stories
  • Test all possible paths through your story!

🎯 Bonus Challenges

  • Add a scoring system based on choices made
  • Include random events using the random module
  • Create a save/load feature using files
  • Add multiple character classes with different abilities
