Medium
Build a cybersecurity tool that analyzes password strength and gives advice on creating secure passwords!

📚 Concepts Tested

  • String variables and methods
  • Boolean variables for conditions
  • Complex conditional logic with multiple criteria
  • String analysis (length, character types)
  • Nested if statements

📋 Requirements

  • Ask user to enter a password
  • Check password length (minimum 8 characters)
  • Check if it contains uppercase letters, lowercase letters, numbers, and symbols
  • Rate the password as Weak, Medium, or Strong
  • Give specific advice on how to improve it
  • Use colors: red for weak, yellow for medium, green for strong
  • Add security-themed emojis

🎨 Rich Examples to Help You

from rich.console import Console from rich.prompt import Prompt from rich.panel import Panel console = Console() password = Prompt.ask("[cyan]Enter password to check[/cyan]", password=True) # Checking different conditions has_upper = any(c.isupper() for c in password) has_lower = any(c.islower() for c in password) has_digit = any(c.isdigit() for c in password) has_symbol = any(not c.isalnum() for c in password) is_long_enough = len(password) >= 8 # Counting how many criteria are met strength_score = sum([has_upper, has_lower, has_digit, has_symbol, is_long_enough]) if strength_score >= 4: console.print("[green]🔒 Strong password![/green]") elif strength_score >= 3: console.print("[yellow]⚠️ Medium strength[/yellow]") else: console.print("[red]❌ Weak password![/red]")

│ 🟡 MEDIUM STRENGTH │
│ │
│ 💡 Try adding some numbers! │

💡 Hints

  • Use password=True in Prompt.ask() to hide the password

Exercise 5: Grade Calculator & Report Card

Hard
Create a comprehensive grade calculator that handles multiple subjects, calculates averages, and generates a beautiful report card!

📚 Concepts Tested

  • Lists for storing multiple grades
  • Dictionaries for subject-grade pairs
  • Float calculations and averages
  • Complex conditional logic for grade boundaries
  • String formatting and manipulation
  • Data validation and error handling

📋 Requirements

  • Ask for grades in 5 different subjects (0-100)
  • Validate that grades are in the correct range
  • Calculate the overall average
  • Convert percentage grades to letter grades (A*, A, B, C, D, U)
  • Determine if the student passes overall (average ≥ 50)
  • Create a beautiful report card using Rich tables and panels
  • Add motivational messages based on performance
  • Use appropriate emojis and colors for different grades

🎨 Rich Examples to Help You

from rich.console import Console from rich.table import Table from rich.panel import Panel console = Console() # Dictionary to store subjects and grades grades = {} subjects = ["Maths", "English", "Science", "History", "Art"] # Getting grades with validation for subject in subjects: while True: try: grade = float(Prompt.ask(f"Enter {subject} grade (0-100)")) if 0 <= grade <= 100: grades[subject] = grade break else: console.print("[red]Grade must be between 0 and 100![/red]") except ValueError: console.print("[red]Please enter a valid number![/red]") # Function to convert percentage to letter grade def get_letter_grade(percentage): if percentage >= 90: return "A*", "green" elif percentage >= 80: return "A", "blue" elif percentage >= 70: return "B", "cyan" elif percentage >= 60: return "C", "yellow" elif percentage >= 50: return "D", "orange" else: return "U", "red" # Creating a report table table = Table(title="📊 Academic Report Card") table.add_column("Subject", style="cyan") table.add_column("Grade %", justify="center") table.add_column("Letter Grade", justify="center") for subject, grade in grades.items(): letter, color = get_letter_grade(grade) table.add_row( subject, f"{grade:.1f}%", f"[{color}]{letter}[/{color}]" ) console.print(table)
Expected Output Example:

│ Subject │ Grade % │ Letter Grade │
│ Maths │ 85.0% │ A │
│ English │ 78.0% │ B │
│ Science │ 92.0% │ A* │
│ History │ 67.0% │ C │
│ Art │ 88.0% │ A │
╰────────────────────────────────────────╯

╭─────── 🎓 Overall Performance ────────╮
│ Average Grade: 82.0% │
│ Overall Grade: A │
│ Status: ✅ PASSED │
│ │
│ 🌟 Excellent work! Keep it up! │
╰───────────────────────────────────────╯

💡 Hints

  • Use a dictionary to store subject names and grades together
  • Use try/except to handle invalid number input
  • Calculate average using sum(grades.values()) / len(grades)
  • Create a function to convert percentages to letter grades
  • Use different colors for different grade ranges
