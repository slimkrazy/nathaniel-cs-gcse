From Boolean Logic to Programming Decisions (10 minutes)

Boolean Logic in Real Life vs Programming:

Real Life Decision Boolean Logic Programming Equivalent
"Can I go out?" Homework done AND Weather good if homework_done and weather_good:
"Should I bring umbrella?" Raining OR Clouds dark if raining or clouds_dark:
"Is password wrong?" NOT (password correct) if not password_correct:

Why We Need Comparison Operators:

The Problem: How do we create Boolean values from data?

  • We have: age = 16
  • We need: A True/False answer to "Can drive?"
  • Solution: age >= 17 returns True or False

Comparison operators convert data into Boolean values for decision-making!

Comparison Operators (15 minutes)

The Six Comparison Operators:

Operator Meaning Example Result
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
< Less than 3 < 5 True
> Greater than 5 > 3 True
<= Less than or equal 5 <= 5 True
>= Greater than or equal 5 >= 3 True

CRITICAL: Assignment vs Equality

# Assignment (storing a value)
age = 16          # Store 16 in variable age

# Equality comparison (checking if equal)
can_drive = age == 17    # Check if age equals 17, store True/False result
print(can_drive)         # False (because 16 ≠ 17)

# Common mistake:
if age = 17:     # ERROR! This tries to assign, not compare
if age == 17:    # CORRECT! This compares

Comparing Different Data Types:

# Numbers
score = 85
passed = score >= 60    # True

# Strings (alphabetical order)
name = "Alice"
comes_before_bob = name < "Bob"    # True ('A' comes before 'B')

# Be careful with mixed types:
age = 16
age_text = "16"
same = age == age_text    # False! (integer 16 ≠ string "16")

Logical Operators - Boolean Logic in Programming (10 minutes)

From Gates to Code:

Remember from Boolean Logic lesson:

  • AND gate: Output True only when BOTH inputs are True
  • OR gate: Output True when AT LEAST ONE input is True
  • NOT gate: Output opposite of input

In Python:

  • and: Both conditions must be True
  • or: At least one condition must be True
  • not: Flips True to False, False to True

Truth Tables in Programming:

AND operator (and):

ABA and B
TrueTrueTrue
TrueFalseFalse
FalseTrueFalse
FalseFalseFalse

OR operator (or):

ABA or B
TrueTrueTrue
TrueFalseTrue
FalseTrueTrue
FalseFalseFalse

Practical Examples:

# AND: Both conditions must be true
age = 16
has_license = False
can_drive = age >= 17 and has_license    # False (age condition fails)

# OR: At least one condition must be true
is_weekend = True
is_holiday = False
can_sleep_in = is_weekend or is_holiday    # True (weekend condition passes)

# NOT: Flip the boolean value
logged_in = True
need_to_login = not logged_in    # False

# Complex combinations
temperature = 25
sunny = True
good_weather = temperature > 20 and sunny    # True (both conditions pass)

IF Statements - Making Decisions (15 minutes)

Basic IF Statement Structure:

Decision Flow:

Condition (Boolean expression) → True? → Execute code block

Condition (Boolean expression) → False? → Skip code block

# Basic if statement
age = 16
if age >= 18:
    print("You can vote!")
    print("Democracy depends on participation!")

print("This always runs regardless of age")

IF-ELSE: Two-Way Decisions

# Two-way decision
score = 75
if score >= 60:
    print("You passed!")
    grade = "Pass"
else:
    print("You failed. Study harder next time.")
    grade = "Fail"

print(f"Your grade is: {grade}")

IF-ELIF-ELSE: Multiple Conditions

# Multiple conditions (like a series of gates)
score = 85

if score >= 90:
    grade = "A"
    print("Excellent work!")
elif score >= 80:
    grade = "B" 
    print("Good job!")
elif score >= 70:
    grade = "C"
    print("Satisfactory")
elif score >= 60:
    grade = "D"
    print("You passed")
else:
    grade = "F"
    print("You failed")

print(f"Your grade is: {grade}")

Key Points About IF Statements:

  • Indentation matters! Code inside if block must be indented (4 spaces or 1 tab)
  • Colon required: Every if/elif/else line ends with :
  • Boolean condition: The condition must evaluate to True or False
  • Only first True executes: In if-elif chain, only first True condition runs

Complex Conditions - Combining Everything (10 minutes)

Combining Comparison and Logical Operators:

# Complex decision making
age = 16
has_permit = True
has_adult = True

# Multiple conditions with AND
if age >= 16 and has_permit and has_adult:
    print("You can drive with supervision")
elif age >= 18:
    print("You can drive alone")
else:
    print("You cannot drive yet")

# Complex conditions with OR
weather = "sunny"
temperature = 22
weekend = True

if (weather == "sunny" and temperature > 20) or weekend:
    print("Great day to go out!")
else:
    print("Maybe stay inside today")

# Using NOT with complex conditions
username = "admin"
password = "secret123"
logged_in = False

if not logged_in and username == "admin" and password == "secret123":
    logged_in = True
    print("Welcome, admin!")
else:
    print("Access denied")

Order of Operations in Boolean Expressions:

Priority Order (highest to lowest):

  1. Parentheses: ()
  2. Comparison operators: ==, !=, <, >, <=, >=
  3. NOT: not
  4. AND: and
  5. OR: or
# Without parentheses
result = True or False and False    # True (and executes first)

# With parentheses for clarity
result = True or (False and False)  # True (same result, but clearer)
result = (True or False) and False  # False (different result!)

Nested IF Statements (5 minutes)

IF Statements Inside IF Statements:

Sometimes we need to make a decision, then make another decision based on that result:

# Nested if statements
weather = "sunny"
temperature = 25
have_sunscreen = False

if weather == "sunny":
    print("It's sunny!")
    if temperature > 25:
        print("It's hot - wear light clothes")
        if have_sunscreen:
            print("Don't forget sunscreen!")
        else:
            print("Buy sunscreen first!")
    else:
        print("Nice temperature for a walk")
else:
    print("Not sunny today")

# Alternative: using logical operators instead of nesting
if weather == "sunny" and temperature > 25 and not have_sunscreen:
    print("Sunny and hot but no sunscreen - buy some!")

Tip: Often you can avoid deep nesting by using logical operators!

Putting It All Together - Complete Program (5 minutes)

Goal: Create a Simple Game Character Stats Checker

# Game character stats program
print("Character Stats Checker")
print("=" * 25)

# Get character stats
name = input("Enter character name: ")
level = int(input("Enter level (1-100): "))
health = int(input("Enter health (0-100): "))
magic = int(input("Enter magic points (0-100): "))

print(f"\n{name}'s Status Report:")
print("-" * 20)

# Check character status using decision making
if health <= 0:
    print("💀 Character is dead!")
    print("Visit a healer immediately!")
elif health < 20:
    print("🚨 Critically injured!")
    if magic > 50:
        print("Use magic to heal yourself!")
    else:
        print("Find a health potion quickly!")
elif health < 50:
    print("⚠️  Injured - be careful")
else:
    print("✅ Healthy")

# Check combat readiness
if level >= 10 and health > 30 and magic > 20:
    print("⚔️  Ready for combat!")
elif level < 10:
    print("🎯 Train more to level up")
elif health <= 30 or magic <= 20:
    print("🛡️  Rest before fighting")

# Special abilities check
if level >= 20 and magic >= 80:
    print("✨ Can cast powerful spells!")
elif level >= 50:
    print("🏆 Master level character!")

print(f"\nThanks for checking {name}'s stats!")

What This Program Demonstrates:

  • Multiple comparison operators (<=, <, >=, >)
  • Logical operators (and, or)
  • Nested if statements
  • If-elif-else chains
  • Complex boolean expressions
  • Real-world decision making in code

Common Mistakes to Address

  • Assignment vs Comparison: Using = instead of == in conditions
  • Indentation Errors: Forgetting to indent code blocks properly
  • Missing Colons: Forgetting : after if/elif/else statements
  • Boolean Logic Errors: Confusing and/or logic (remember your truth tables!)
  • Comparison Precedence: Not using parentheses for complex conditions
  • Data Type Mixing: Comparing strings with numbers without conversion
