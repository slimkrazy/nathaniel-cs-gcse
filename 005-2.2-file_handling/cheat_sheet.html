What is a File?

Definition: A file is a named collection of bytes stored on your hard drive/SSD.

Key Point: Everything in a file is just bytes - different file types organize those bytes differently!

Example: hello.txt Content: "Hello" Bytes (hex): 48 65 6C 6C 6F Bytes (dec): 72 101 108 108 111 Characters: H e l l o

File Extensions

What: The part after the dot (.) that hints at the file type

Format: filename.extension

Important: Extensions are just hints! The actual bytes determine what the file really is.

Extension File Type Example
.txt Plain text notes.txt
.py Python code game.py
.jpg / .jpeg JPEG image photo.jpg
.png PNG image logo.png
.mp3 Audio file song.mp3
.pdf PDF document report.pdf
.docx Word document essay.docx

Magic Bytes (File Signatures)

What: Special byte patterns at the start of files that identify their real type

Why: This is how computers REALLY know what type of file it is!

File Type Magic Bytes (Hex) As Text
JPEG Image FF D8 FF -
PNG Image 89 50 4E 47 .PNG
PDF Document 25 50 44 46 %PDF
MP3 Audio 49 44 33 ID3

Plain Text vs Binary Files

📝 Plain Text Files

Contains: Human-readable text characters

Can open in: Any text editor

Examples:

  • .txt (text files)
  • .py (Python code)
  • .html (web pages)
  • .csv (data)

⚙️ Binary Files

Contains: Non-text data (images, audio, etc.)

Can open in: Specific programs only

Examples:

  • .jpg, .png (images)
  • .mp3, .wav (audio)
  • .pdf (documents)
  • .exe (programs)

Python File Modes

Mode Name What it Does Creates File?
"r" Read Open for reading only (file must exist) No - Error if doesn't exist
"w" Write Open for writing (OVERWRITES existing content!) Yes
"a" Append Open for writing (ADDS to end of file) Yes
⚠️ Warning: Mode "w" will ERASE the entire file! Use "a" to add to the end instead.

File Operations - Quick Reference

1️⃣ Opening a File

file = open("filename.txt", "mode")

Replace "mode" with "r", "w", or "a"

2️⃣ Reading from a File

# Read entire file content = file.read() # Read line by line for line in file: print(line.strip()) # Read all lines into list lines = file.readlines()

3️⃣ Writing to a File

# Write a line file.write("Hello World\n") # Write multiple lines file.write("Line 1\n") file.write("Line 2\n")

Remember: Add \n for new lines!

4️⃣ Closing a File

file.close()

Always close files when done!

The 'with' Statement (Best Practice)

✨ Better Way: Use 'with' statement - automatically closes the file!

# Reading with open("data.txt", "r") as file: content = file.read() print(content) # File automatically closed here! # Writing with open("output.txt", "w") as file: file.write("Hello World\n") # File automatically closed here!
Why use 'with'?
  • Automatically closes file (even if error occurs)
  • Cleaner code
  • Recommended best practice

Common Patterns

Pattern 1: Read and Display

with open("story.txt", "r") as file: content = file.read() print(content)

Pattern 2: Write Multiple Lines

with open("list.txt", "w") as file: file.write("Item 1\n") file.write("Item 2\n") file.write("Item 3\n")

Pattern 3: Read Numbers from File

with open("scores.txt", "r") as file: for line in file: score = int(line.strip()) print(score)

Pattern 4: Append to Log File

with open("log.txt", "a") as file: file.write("New entry\n")

Pattern 5: Save and Load Single Value

# Save score = 1000 with open("score.txt", "w") as file: file.write(str(score)) # Load with open("score.txt", "r") as file: score = int(file.read()) print(score)

Important Methods

Method What it Does Returns
file.read() Read entire file String with all content
file.readline() Read one line String (one line)
file.readlines() Read all lines List of strings (one per line)
file.write(text) Write text to file Number of characters written
file.close() Close the file Nothing
line.strip() Remove \n and spaces Cleaned string

Common Mistakes to Avoid

❌ Mistake 1: Forgetting to close the file
# BAD file = open("data.txt", "r") content = file.read() # Missing file.close()!
✅ Fix: Use 'with' statement or remember to close()
❌ Mistake 2: Wrong mode for operation
# BAD - Can't write in read mode! file = open("data.txt", "r") file.write("Hello") # ERROR!
✅ Fix: Use "w" or "a" mode for writing
❌ Mistake 3: Using "w" when you mean "a"
# BAD - This erases the file! file = open("log.txt", "w") file.write("New entry\n")
✅ Fix: Use "a" to append instead
❌ Mistake 4: Forgetting to convert types
# BAD - Reading gives strings! score = file.read() # "100" (string) total = score + 50 # ERROR!
✅ Fix: Convert with int()
score = int(file.read()) # 100 (integer) total = score + 50 # Works!
❌ Mistake 5: Forgetting newlines when writing
# BAD - Everything on one line! file.write("Line 1") file.write("Line 2")
✅ Fix: Add \n
file.write("Line 1\n") file.write("Line 2\n")

Complete Examples

Example 1: Save High Score

# Save score = 1500 with open("highscore.txt", "w") as file: file.write(str(score)) # Load with open("highscore.txt", "r") as file: saved = int(file.read()) print(f"High score: {saved}")

Example 2: Process a List of Numbers

with open("numbers.txt", "r") as file: total = 0 count = 0 for line in file: num = int(line.strip()) total += num count += 1 average = total / count print(f"Average: {average}")

Example 3: Shopping List Manager

# Add items items = ["Milk", "Bread", "Eggs"] with open("shopping.txt", "w") as file: for item in items: file.write(item + "\n") # Read items with open("shopping.txt", "r") as file: for line in file: print("- " + line.strip())

Key Points to Remember

  • Files are collections of bytes with names
  • Extensions are hints, magic bytes are the truth
  • Plain text = readable, Binary = needs special program
  • Always close files (or use 'with')
  • "r" = read, "w" = write (overwrites!), "a" = append
  • Reading gives strings - convert with int() if needed
  • Add \n for new lines when writing
  • Use strip() to remove \n when reading
