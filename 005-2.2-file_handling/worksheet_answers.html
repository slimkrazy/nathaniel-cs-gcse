Question 8 (3 marks)

Look at this Python code:

file = open("scores.txt", "w") file.write("100") file.write("200") file.close()

(a) What will be the contents of scores.txt after this code runs? (1 mark)

Answer: 100200 (on one line / all together / concatenated)

Marking: 1 mark for showing the numbers together without a line break.

(b) The programmer wanted each score on a separate line. What should they change? (2 marks)

Answer: Add \n (newline character) after each score / at the end of each write statement.

file.write("100\n") file.write("200\n")

OR use separate write() calls for each newline

Marking: 1 mark for mentioning \n or newline, 1 mark for showing correct placement in code.

Section C: Writing File Handling Code (12 marks)

Question 9 (3 marks)

Write Python code to open a file called "message.txt", read its entire contents, and print them to the screen. Make sure to close the file properly.

Answer (Method 1 - Basic):

file = open("message.txt", "r") content = file.read() print(content) file.close()

Answer (Method 2 - Using 'with'):

with open("message.txt", "r") as file: content = file.read() print(content)
Marking:
  • 1 mark for correctly opening file in "r" mode
  • 1 mark for reading and printing the content
  • 1 mark for closing the file (or using 'with' statement)
Accept: Both methods, or variations that accomplish the same goal.

Question 10 (4 marks)

Write Python code that asks the user for their name and age, then saves both pieces of information to a file called "userdata.txt". Each piece of data should be on a separate line.

Answer (Method 1 - Basic):

name = input("Enter your name: ") age = input("Enter your age: ") file = open("userdata.txt", "w") file.write(name + "\n") file.write(age + "\n") file.close()

Answer (Method 2 - Using 'with'):

name = input("Enter your name: ") age = input("Enter your age: ") with open("userdata.txt", "w") as file: file.write(name + "\n") file.write(age + "\n")

Answer (Method 3 - f-strings):

name = input("Enter your name: ") age = input("Enter your age: ") with open("userdata.txt", "w") as file: file.write(f"{name}\n{age}\n")
Marking:
  • 1 mark for getting user input (both name and age)
  • 1 mark for opening file in "w" mode
  • 1 mark for writing both values with newlines (\n)
  • 1 mark for closing the file (or using 'with')

Question 11 (5 marks)

Write Python code that reads scores from "scores.txt", calculates the average, and prints it.

Answer (Method 1 - Basic loop):

file = open("scores.txt", "r") total = 0 count = 0 for line in file: score = int(line.strip()) total = total + score count = count + 1 file.close() average = total / count print(f"Average score: {average}")

Answer (Method 2 - Using readlines):

with open("scores.txt", "r") as file: lines = file.readlines() total = 0 for line in lines: total = total + int(line.strip()) average = total / len(lines) print(f"Average score: {average}")

Answer (Method 3 - List comprehension - Advanced):

with open("scores.txt", "r") as file: scores = [int(line.strip()) for line in file] average = sum(scores) / len(scores) print(f"Average score: {average}")
Marking:
  • 1 mark for opening the file in "r" mode
  • 1 mark for reading lines/looping through file
  • 1 mark for converting strings to integers
  • 1 mark for calculating total and count/average correctly
  • 1 mark for closing file (or using 'with') and printing result
Note: Award marks for correct logic even if syntax varies.
Key concepts tested:
  • Reading file line by line
  • Converting string to integer (int())
  • Using strip() to remove newline characters
  • Accumulating a total
  • Counting items
  • Calculating average (total ÷ count)

Section D: Problem Solving (8 marks)

Question 12 (4 marks)

Identify and fix the TWO errors in this code:

file = open("data.txt", "r") file.write("Hello World") print(file.read()) # File never closed

Error 1: Trying to write to a file opened in read ("r") mode

How to fix: Change mode to "w" OR remove the write statement (depending on intention)

Error 2: File is never closed

How to fix: Add file.close() at the end OR use 'with' statement

Corrected code (assuming intent is to write):

file = open("data.txt", "w") file.write("Hello World") file.close()

OR (assuming intent is to read):

file = open("data.txt", "r") print(file.read()) file.close()
Marking:
  • 1 mark for identifying mode error
  • 1 mark for correct fix to mode error
  • 1 mark for identifying missing close
  • 1 mark for showing how to fix (adding close() or 'with')

Question 13 (4 marks)

A game needs to save the player's high score. Explain the steps needed.

Answer:

  1. When game starts:
    • Try to open "highscore.txt" in read mode ("r")
    • If file exists, read the high score and convert to integer
    • Close the file
    • If file doesn't exist, set high score to 0
  2. During gameplay:
    • Track the current score
    • No file operations needed while playing
  3. When game ends:
    • Compare current score with loaded high score
    • If current score > high score:
    • Open "highscore.txt" in write mode ("w")
    • Write the new score to file
    • Close the file
Marking:
  • 1 mark for reading/loading score at start (mentioning read mode)
  • 1 mark for handling case when file doesn't exist
  • 1 mark for comparing scores
  • 1 mark for writing new score if higher (mentioning write mode)
Accept: Bullet points, flowchart, or paragraph form with correct logic.
Sample implementation:
# Load high score try: with open("highscore.txt", "r") as file: high_score = int(file.read()) except: high_score = 0 # Play game current_score = 150 # Example # Save if better if current_score > high_score: with open("highscore.txt", "w") as file: file.write(str(current_score)) print("New high score!")

Common Mistakes to Watch For

When reviewing Nathaniel's work, look for these common errors:

  • Forgetting to close files - Emphasize using 'with' statement
  • Wrong file mode - Can't write to "r" mode or read from "w" mode
  • Mode "w" overwrites - Students often use "w" when they mean "a"
  • Not converting types - Reading numbers as strings, need int() conversion
  • Forgetting newlines - Writing without \n causes everything on one line
  • Not using strip() - Newline characters can cause issues when reading
  • File doesn't exist error - Need to handle case when reading non-existent file
