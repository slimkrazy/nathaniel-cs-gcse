Section C: Writing File Handling Code (12 marks)

Question 9 (3 marks)

Write Python code to open a file called "message.txt", read its entire contents, and print them to the screen. Make sure to close the file properly.

Hint: You need three steps: open the file, read it, close it. Which mode do you need for reading?

Question 10 (4 marks)

Write Python code that asks the user for their name and age, then saves both pieces of information to a file called "userdata.txt". Each piece of data should be on a separate line.

Hint: Use input() to get the data, open() to create the file (which mode?), write() to save the data (don't forget \n for new lines), and close() when done.

Question 11 (5 marks)

A file called "scores.txt" contains the following data (each score on a separate line):

85 92 78 95 88

Write Python code that:

  1. Opens the file
  2. Reads all the scores
  3. Calculates and prints the average score
  4. Closes the file
Hints:
  • Use a loop to read each line
  • Convert each line to an integer using int()
  • Use a variable to keep a running total
  • Count how many scores there are
  • Average = total ÷ count

Question 13 (4 marks)

Explain, using bullet points, the steps the program needs to take. Include which file operations (open, read, write, close) are needed at each step.

Self-Assessment Checklist

After completing this worksheet, you should be able to:

Explain what a file is (bytes stored on disk)
Identify file types from their extensions
Understand the difference between plain text and binary files
Know what file modes "r", "w", and "a" mean
Write code to open and close files
Write code to read from files
Write code to write to files
Debug common file handling errors
